# 制式改造 (ColonistModification)

RimWorld 1.6 / 1.7 模组——为殖民者批量标准化植入仿生部件和异种基因。

## 解决的痛点

- **逐人逐部位手动操作**：原版需要打开每个人的健康面板，从长列表里找到对应植入物，还要区分左右部位，几十个殖民者累计要操作上百次。
- **人工跟踪材料状态**：钢铁、零部件是否充足全靠记忆，或需要手动查询仓库。
- **缺少批量模板**：不能一次定义「给这几个人安装仿生臂×2、仿生腿与仿生眼」，然后等待自动推进。
- **装完一侧即视为完成**：装完左臂后系统不会提醒右臂尚未安装，直到玩家主动检查才会发现。

## 功能

- **自定义改造模板**：创建手术模板，选择植入物（仿生臂、腿、眼、脊椎等）与基因植入（异种胚芽），一次定义即可批量复用。
- **批量分配**：在概览页为多个殖民者分配同一模板。
- **自动检测与通知**：系统定期检查资源、医生与身体部位，条件满足时弹出确认窗或自动添加手术；缺少材料时会显示具体物品名与库存数量。
- **部位分立追踪**：左臂与右臂、左眼与右眼各自独立追踪完成状态；不分左右的部位（脊椎、基因植入）单独处理。
- **基因植入支持**：模板可指定目标异种，自动搜索地图上匹配的胚芽并绑定到手术单；植入完成后通过检测殖民者的异种变化判定完成。
- **实时完成判定**：直接从殖民者的健康状态与异种特征检测进度，不写入存档，也不额外记录。
- **手术并发控制**：限制同时进行的手术数量，避免医疗资源被同时占满。
- **取消分配不丢数据**：取消模板分配后重新分配，已完成的部位记录仍然保留。

## 开发

```bash
dotnet build
```

输出：`publish/1.7/Assemblies/ColonistModification.dll`

推荐创建目录链接到 mod 目录：

```bash
mklink /D F:\SteamLibrary\steamapps\common\RimWorld\Mods\ColonistModification F:\RiderProjects\ColonistModification\publish
```
